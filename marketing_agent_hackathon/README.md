# Marketing Agents Hackathon: Build Your Own GTM Agents

Reference notes for the **in-person** hackathon presented by **The AI Collective × Lynk**. Goal: turn GTM busywork into **autonomous agents** that find ICPs, qualify leads, ship campaigns, and report results—wired into real tools (CRM, ads, outbound, analytics).

**Bring:** a real funnel problem. **Leave:** a working marketing copilot and a path to ship after the event.

## What to build (framing from the event)

Go beyond one-off prompts. Aim for **orchestrated agent systems** that:

- Drive **measurable** marketing outcomes  
- Include **guardrails** credible for real teams  
- **Plan, execute, and self-correct** end-to-end GTM workflows
