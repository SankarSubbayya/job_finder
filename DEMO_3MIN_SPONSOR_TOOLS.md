### PART 3: SPONSOR TOOLS BREAKDOWN (2:15 - 3:00)

**Here's how Kalibr, Apify, and Claude work together:**

#### 🟦 KALIBR (Multi-Model Orchestration)

> "Kalibr routes each agent to the optimal model for **cost** and **quality**."

**In Throughline:**
- **Agent 1 (Profile Search):** Kalibr routes to **Apify** for web scraping (specialized tool, $0.15/query)
- **Agent 2 (Validation):** Kalibr routes to **Claude Opus** for deep reasoning (40% cheaper than other LLMs, better accuracy)
- **Agent 3 (Compliance Gate):** Rules engine (no LLM cost)
- **Agent 4 (Outreach):** Kalibr routes to **Claude Sonnet** for personalized messaging (14x cheaper than Opus, fast)
- **Agent 5 (Governance):** Log aggregator (no LLM cost)

**Kalibr's Win:** 40% cost savings vs. using Claude Opus for everything.

---

#### 🟧 APIFY (Web Scraping)

> "Apify finds REAL prospects. Not mock data. Not hallucinations."

**In Throughline:**
- Scrapes Google Search results for "CFOs at fintech companies"
- Returns real company names, URLs, snippets
- Cost: $0.15 per query
- Reliability: 99.9% uptime

**Apify's Win:** Real data pipeline. No AI hallucinations on prospect discovery.

#### 🟨 CLAUDE AI (Reasoning + Personalization)

> "Claude powers validation, compliance reasoning, and personalized outreach."

**In Throughline:**

- **Sonnet (Outreach):** Fast personalization at scale

**Claude's Win:** Production-grade reasoning for compliance + speed.
